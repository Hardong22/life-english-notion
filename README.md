# 生活英语陪练

中文 | [English](README.en.md)

在 Codex 里聊聊今天发生的事，顺便练习怎么用英语说。想练点单、面试或工作沟通时，也可以随时进入角色扮演。练习结束后，可以把总结和需要复习的表达存到你指定的 Notion 页面。

这是一个可安装、可在新会话中调用的 Skill。你不需要另外运行网页。文字聊天可以直接用；语音需要客户端支持，保存到 Notion 则需要连接 Notion 并指定位置。

## 安装与开始

在 Codex 中发送：

```text
使用 $skill-installer 安装 https://github.com/Hardong22/life-english-notion
```

Skill 在仓库根目录。如果安装器询问路径，告诉它使用根目录，并命名为 `life-english-notion`。具体安装方式见 [OpenAI Skills Catalog](https://github.com/openai/skills)。同名 Skill 只安装一份。

安装后开一个新会话：

```text
使用 $life-english-notion，开始今天的英语陪练。
```

先试着用英语讲。卡住时可以描述意思，或用中文补充。默认等你说完再反馈，一次处理一个问题。说 “I'm finished” 表示这一段讲完了；说 “Let's wrap up” 或“今天到这”才结束本次练习。

想直接练场景，也可以说：

```text
使用 $life-english-notion，模拟一次咖啡店点单，直接开始，不用预习。
```

## 按自己的节奏练

| 你说 | 接下来会怎样 |
|---|---|
| 我还没说完 | 等你继续，不追加问题或纠错 |
| 给点提示，不要直接说整句 | 先给方向、关键词或句框 |
| 逐句纠正我 | 每句结束后处理一个问题 |
| 先别纠错 | 暂停反馈，继续当前话题 |
| 这段不记录 | 继续聊天，但不把这段纳入练习记录和总结 |
| 我在录视频 | 暂停插话、纠错和练习记录，结束录制后恢复此前状态 |
| 今天到这，整理一下 | 退出角色并复盘，按约定决定是否保存 |

“不记录”控制的是 Skill 整理和保存的内容，无法关闭客户端自身的聊天历史或服务端留存。

## 切换解释语言

随时说“解释用中文”“Explain in English”或“解释中英双语”。这会改变用法说明、纠错原因和复盘解释的语言，练习对话仍以英语为主。需要改变练习对话的语言时，直接说“接下来只用英语”或“先用中文聊”。

切换语言不会解除暂停记录，也不会退出当前角色。新会话只恢复实际保存并读取到的偏好。

## 保存到 Notion

没有 Notion 也能练，结束后先在聊天里看总结即可。

第一次保存时，连接 Notion，把目标页面链接发给 Skill。若想以后自动保存，可以说：

```text
以后练习结束后保存到这个页面。请把目标位置和保存偏好存在本地，供新会话使用。
```

Skill 会核对页面，再使用现有结构；没有结构时，从根页面下的会话页开始。真实经历、计划和角色台词会分开记录。看过示范、跟读和独立说对也会分别标明。

本地偏好使用 `preferences.local.md`，格式见 [设置模板](preferences.example.md)。它不应包含密钥或对话历史。聊天记录不会随 Skill 自动带到新会话；回顾历史需要读取指定的 Notion 页面。

Notion 暂时不可用时，Skill 会说明还没有保存。你要求保留后，可将草稿放入当前工作目录的 `private-records/`，恢复连接后查重再同步。若该工作目录属于另一个 Git 仓库，也要在那里排除这个目录。

## 隐私与限制

公开仓库只放技能规则、文档和检查脚本。本地设置、练习记录、转写、凭据都不属于发布内容。发布前的检查方式见 [维护说明](docs/DESIGN.md)。

语音断句由客户端控制，所以“等我说完”的规则不能保证麦克风永远不抢话。Skill 没有发音评分引擎；文本也不能证明发音水平。真实语音、Notion 写入及跨会话恢复仍需在使用环境中验证。

项目检查能发现部分文件、链接和隐私问题，不能证明每次对话都符合教学规则，也不能保证检测到所有敏感信息。更改规则后，可按 [行为试用场景](docs/BEHAVIOR.md) 检查实际表现。
