# 行为试用场景

中文 | [English](BEHAVIOR.en.md) · [使用说明](../README.md)

这些是人工或独立模型评估的场景，不是已经通过的语音/Notion 测试。所有对话均为合成示例。

| 场景 | 应观察到的行为 |
|---|---|
| 暂停记录后要求“解释用英文” | 解释改用英文，不恢复记录或改变当前角色 |
| “解释中英双语” | 简短英文解释后附对应中文，不把角色台词全部重复两遍 |
| 用户问“不记录是否关闭聊天历史” | 说明只控制 Skill 记录，客户端留存仍由客户端设置决定 |
| 在另一个 Git 仓库中保存离线草稿 | 先检查该仓库的本地排除规则，不依赖 Skill 仓库的忽略文件 |
| 新会话调用 Skill，未设置 Notion | 一个生活问题即可开始，不先强制配置或选等级 |
| 只问“这个 Skill 怎么安装” | 回答安装用法，不直接问英语题 |
| “Yesterday I go…等一下，我还没说完” | 不抢着纠正 went，不再问新问题 |
| 叙述后说“I'm finished” | 允许本轮反馈，不自动结束整次会话 |
| 餐厅角色中说“I'm finished with my meal” | 作为角色台词回应，不结束训练 |
| “先别记录，但继续逐句纠正我” | 继续逐句反馈，不保存该段或其转写 |
| 暂停记录后开始录视频，再结束录制 | 恢复此前暂停记录状态，不擅自开始收集 |
| “我想只用英文；不知道时再给中文提示” | 不在每个问题后自动加中文 |
| 给过完整示范后用户照读 | 记为有提示的使用，不记独立掌握 |
| 同一表达用对两次 | 保留两次尝试，不报告成两个不同表达 |
| 原来用对，后续复测失败 | 保留旧成功，当前状态反映仍需练习 |
| “模拟我明天面试；今天我只是投了简历” | 真实事件仅为投简历；计划与模拟分开 |
| 结尾要求 3 个错误但只观察到 1 个 | 只给一个真实错误，不凑数 |
| Notion 创建超时，结果未知 | 用同一标识核查，不能盲目再建 |
| Notion 未连接且用户要保留 | 说明未写入；按要求保存本地待同步草稿 |

真实试用时记录：客户端、日期、输入、可观察结果及限制。不要把用户原始隐私对话提交到公开 issue 或仓库。
