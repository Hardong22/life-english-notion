# 记录与复习依据

## 结束一次对话

按实际内容给简短总结，避免没有材料的空栏目：

- 真实生活：中文概括用户明确讲述的事件；计划、假设单独标明。只在对话支持时记情绪，含糊感受保留不确定性，不推断人格。仅记录用户提出的待办，不把教练建议变成用户承诺。
- 本次练习：模式、场景、任务结果；只写已知等级和真实时长，未知留空或标未测量。
- 做得好的地方：给实际例子，不凭一次表现宣称“比以前进步”。历史对比需要可访问、可比较的先前证据。
- 最值得修正的表达：最多 3 个。每项保留原话，给一个改法和短原因。没有错误就说没有观察到值得优先修正的问题，不凑 3 个。
- 可升级的说法：最多 3 个，仅在有价值时提供，清楚标为可选表达，不把正确原句改称错误。
- 下次重点：一两个可执行的语言目标；若用户愿意，给一个 2–5 分钟、情景稍有变化的练习。

一次纠正一个问题指互动节奏；结尾可以集中列少量反馈，不强制用户逐条回答。中文生活摘要是记录格式；给用户的口头英语反馈仍遵循当前语言偏好。

## 表达证据

每个值得复习的表达保存：表达、中文意思（有必要时）、真实情境、用户原话或明确标注的摘要、帮助类型、本次结果、下次复测方向。用户原话缺失时不生成假引语。

| 状态 | 依据 |
|---|---|
| 未观察到 | 没有公平的表达机会，或只有 AI 示例。 |
| 需提示 | 依靠中文方向、英文关键词或完整示范才能完成，注明提示类型。 |
| 独立用对一次 | 没有针对该表达的提示，且意思、形式与场景合适。 |
| 复测通过 | 后续不同问题或另一会话中再次独立用对，附两次证据；只是跟读不算。 |
| 需再练 | 已有尝试但仍出错，或复测遇到困难；保留过去成功证据。 |

同一表达的历史尝试逐条保留，当前状态以最近相关证据为依据。“已用对次数”与“不同表达数量”分开；不要把重复记录相加后称为已掌握词汇量，也不输出未经验证的熟练度百分比。

### 最小证据结构与核对

这是一份逻辑记录格式，可写成 Notion 页内表格，不要求另外建立数据库或运行本地网页。

| 对象 | 至少保留什么 |
|---|---|
| 会话 | 稳定会话标识、主题、可确认的发生日期/时间、材料范围、已知偏好；保存后附页面链接 |
| 场景段 | 日常事实或角色模拟、具体主题和任务；计划与假设在内容中另标，不因同日而混成一次事件 |
| 表达尝试 | 表达及其当前意思、对应场景、真实用户话语或标注摘要、帮助类型、对错/未观察、本次状态 |
| 复测 | 新问题、这次是否给提示、真实作答、关联的旧证据；没有作答就不生成通过状态 |

保存前交叉核对，而不是只检查状态名称是否在列表里：

- 只有 AI 说过：未观察到，不能标独立或复测通过。
- 用户在完整示范后复述：记为需提示；如果仍然出错，记需再练，保留示范帮助类型。
- 复测通过：需要本次独立正确证据及可访问的先前相关证据；只是给出了下一次题目不成立。
- 独立用对后又复测失败：追加新尝试，当前标需再练；不能继续沿用旧的绿色“已掌握”，也不能删除旧成功。
- 原话和来源缺失：保留为待核对摘要，不编造引用或升级为确证的掌握。
- 时间、水平不明确：保留未知；不从字符串看起来像时间就认为时间有效，不从一次文本答句推断 CEFR 等级。

复习聚合时按“表达及其意思/用法”识别同一项目，再根据最新相关尝试整理状态。不要仅靠大小写或字面相似把不同意思合并。历史进步与当前困难可以同时展示；未观察到要明确标注，不能用与成功相同的颜色或文字暗示已会。

## 周复盘 / 按需回顾

只在用户要求时进行，不默认建立定时任务。读取指定范围的真实记录，说明覆盖的日期和缺失部分。

先简短回看真实生活中的主题或变化，再从需提示、需再练的表达中选少量复测。题目在前，答案单独折叠或放到独立答案页，不在题干泄露目标表达。Notion 折叠格式按当前连接器规范生成并回读；不能确认折叠效果时使用独立答案页并如实说明。

用户实际作答后才更新状态；仅生成题目或用户点开答案，不算完成复习。用新的语境检验能否迁移，跟读答案只作为模仿记录。

## 原始材料

原始转写与摘要分开存放，明确材料范围（完整可用记录、部分转写、仅摘要）。不得翻译、去重或润色后再叫原始逐字稿；展示性截取须标明节选。没有音频证据时发音写“未评估”，不从拼写推断发音。明确不记录的内容也不能出现在转写附件或复盘里。
